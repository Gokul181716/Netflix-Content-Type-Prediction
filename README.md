# Netflix Content Type Prediction Model

## Project Overview
This project uses Machine Learning to predict whether a Netflix title is a Movie or a TV Show based on its metadata.

## Dataset
- Total records: 8,790
- Movies: 6,126
- TV Shows: 2,664

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Machine Learning Algorithm
Random Forest Classifier

## Features Used
- Release Year
- Director
- Country
- Rating
- Listed In (Genre)

## Model Performance
- Test dataset: 1,758 records
- Accuracy: 98.29%
- Correct predictions: 1,728

## Project Files
- `Netflix_Content_Type_Prediction.ipynb`: Complete source code and results
- `Netflix_Content_Type_Model.pkl`: Trained model
- `Dataset.csv`: Dataset used for training, if redistribution is permitted
- `requirements.txt`: Required Python libraries
- `screenshots/`: Model evaluation screenshots

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Open the Jupyter notebook.
3. Run the notebook cells to train and evaluate the model.
